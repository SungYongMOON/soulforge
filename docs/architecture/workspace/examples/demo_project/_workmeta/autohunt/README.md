# autohunt

- 이 경로는 tracked auto-hunt policy example 만 둔다.
- 여기의 sample 은 mailbox routing, monster classification, workflow-party selection 규칙만 보여준다.
- compact queue/retry/monster state와 run receipt는 local `_workmeta/<project_code>/autohunt/`와 `runs/<run_id>/`에 두고, raw run truth와 artifact는 workspace/worksite에 둔다.
