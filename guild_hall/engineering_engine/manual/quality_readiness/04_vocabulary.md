# 04. Vocabulary

Common chassis: [../04_vocabulary.md](../04_vocabulary.md).

E01 reuses kernel gap values `satisfied`, `gap_missing`, `gap_unknown`, and `gap_conflict`. It adds no shared gap state. A domain-only `not_applicable` is possible only after all five applicability components resolve, one is explicitly false, and an exact basis ref is supplied. Results name `canon_claim_ceiling` and `evidence_claim_ceiling` separately. Source-native artifacts preserve `artifact_token: null`; near-synonym mapping is refused.
