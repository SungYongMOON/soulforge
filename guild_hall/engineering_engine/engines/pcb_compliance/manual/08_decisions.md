# 08. Decisions

The following decisions are intentionally outside this package: standard adoption, lawful access
to a controlled body, standard class/addendum selection, project applicability, workmanship
acceptance, repair/disposition approval, and production release. A controlled-standard row stays
`UNKNOWN/HOLD` until a Human Owner resolves those decisions in the private project plane.

No package-owned Profile source adoption or registry is invented in this package; caller-added Profile
rules are clamped to `observed` at most. Public safe locator and string guards ensure private/secret sentinels,
credentials, file URIs, POSIX/Windows paths, and internal network endpoints are rejected without echoing.
JSON Schemas are closed under Draft 2020-12 strict mode; cross-field semantic invariants are strictly
enforced by the deterministic runtime evaluator.
