# 07. Runs and receipts

Common chassis: [../07_runs_and_receipts.md](../07_runs_and_receipts.md).

The public-synthetic runner imports literals only and prints deterministic JSON to stdout. Its receipt contains schema, digests, counts, exact execution/source/rule-stage-Owner bindings, and zero-valued effect counters; it contains no source body, project payload, decision, or task data.
