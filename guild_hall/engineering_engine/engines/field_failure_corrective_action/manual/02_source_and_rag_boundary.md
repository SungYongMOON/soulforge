# 02 — Source and RAG boundary

The source packet lists three directly checked official public sources. NRC Appendix B supports
narrow quality-assurance evidence categories; NRC Part 21 gives a sector-specific
deviation/evaluation/reporting example; the FDA QMSR source is a boundary reminder because its
incorporated ISO body was not accessed.

No source is treated as inherently applicable to a project. Each actual caller must provide a
non-floating source revision and project applicability binding. A changed public source is a new
candidate, not a silent ruleset update.

RAG is excluded from this package. It may help another authorized process discover a source, but
it cannot add a rule, satisfy a row, resolve a conflict, select a disposition, or close a case.
Missing protected or private material stays `UNKNOWN/HOLD`.
