# 06. Evidence trace

Each result retains the candidate rule/source locator, lifecycle token, required and missing
evidence/authority fields, human-binding evidence state, written-record evidence state, conflict
count, and governing authority family when a valid Core conflict record exists.

The receipt carries digests, counts, exact source/ruleset refs, accepted-rule bindings, and zero
effect counters. It contains no raw source body, project payload, human name, signature,
decision, or private path.
