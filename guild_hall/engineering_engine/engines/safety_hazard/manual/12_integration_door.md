# 12. Integration door

Integration remains a factory-owned operation. The domain task requests manifest/topology and
generated-conformance work through `topology/safety_hazard_integration_request_v0.md`; it does
not edit shared Core, registry schemas, root scripts, whole-engine manifests, release artifacts,
or Watchtower federation.

No production module, writer, MCP server, registry, external route, live project binding, or
acceptance action is created by this package.
