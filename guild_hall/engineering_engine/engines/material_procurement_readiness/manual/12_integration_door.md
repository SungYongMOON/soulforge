# Integration door

The package is not statically wired into global topology, release, root scripts, or a live ERP
binding. Importing the evaluator follows the existing in-memory Core self-registration idiom only.

Shared manifest/topology/release regeneration and any global registration are owned by the
sequential integration lane described in [../topology/integration_request_v0.md](../topology/integration_request_v0.md). This manual does not authorize main merge, canon promotion,
production activation, or any writer/action authority.
