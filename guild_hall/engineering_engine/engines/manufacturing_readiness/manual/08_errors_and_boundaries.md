# Errors and public/private boundary

Malformed, duplicate, incomplete, payload-bearing, private-path-bearing,
accessor-backed, Proxy-backed (including revoked), symbol-bearing, hidden,
sparse, cyclic, custom-prototype, or unsupported input is refused with a closed
error code before a caller getter or handler trap is observed.
Receipts contain digests, locked public package references, counts, and zero
effect counters only. They do not include source bodies, evidence payloads,
absolute paths, credentials, or hidden reasoning.

The code's input guard is not permission to load private data. Actual project
records remain under their Project Binding owner.
