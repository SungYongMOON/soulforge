# 01. Purpose and boundary

E02 compares two or more declared ends of one equipment, board, connector, or
cross-domain interface record. It provides structural consistency findings, not
engineering approval.

The package owns source-linked category names, rule metadata, a bounded Profile
applicability operation, a pure compiler/evaluator, synthetic fixtures, tests, and
a zero-write runner. It does not own organization conditions, project constraints,
source documents, source extraction, applicability decisions, value conversions,
or acceptance authority.

`satisfied` means all explicitly required typed facts in scope agree. It never means
the interface is safe, compliant, verified, approved, or suitable for use.
