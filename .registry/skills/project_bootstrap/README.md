# Project Bootstrap Launcher

Thin Codex launcher for `.workflow/development_team1_project_bootstrap_v0`.

It makes the repeatable project-start procedure callable as `$soulforge-project-bootstrap` after scoped skill sync. The workflow, not this skill, owns classification, number preview, storage boundaries, packet templates, compatibility gates, runtime planning, first-work canary, and review closeout.

```powershell
npm.cmd run skills:sync -- project_bootstrap
```

The launcher does not create projects, people assignments, external collaboration surfaces, routes, automation, budgets, baselines, or acceptance without the workflow's exact authority gates.
