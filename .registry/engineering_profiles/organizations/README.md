# Organization Profile Catalog

## Purpose

This directory serves as the public-safe catalog owner surface for Organization Profiles.

## Public-Safe Guard Policy

- Only public-safe schemas, metadata, synthetic examples, and non-sensitive rule tailoring are stored here.
- Customer-private, company-private, contract payloads, source bodies, and absolute paths are strictly forbidden.
- Actual private organization profile sources reside in `_workspaces/knowledge/organizations/<organization_id>/<domain_engine_id>/`.
- The legacy tracked `system_dev_lig_grade_a.prime.overlay.json` is classified as legacy `HOLD` and is not promoted as a public catalog exemplar.
